# Apexline Commercial Systems

Static HTML landing page concept.

## Open locally

Open `index.html` in a browser, or run a local server:

```bash
python3 -m http.server 8000
```

- `styles.css`
- `script.js`

- `terms.html`
- `404.html`
- `SEO-README.md`
