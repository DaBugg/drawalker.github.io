Accessibility

S&L is committed to making its website usable for a broad range of visitors.

This website is designed with semantic structure, visible keyboard focus, responsive layouts, descriptive image text, sufficient color contrast, clear form labels, and reduced-motion support.

Need help?

If you have difficulty accessing information or completing an action on this website, call (914) 908-6990 or email info@slplumbing.net. Please describe the page, the information you need, and the assistive technology or browser you are using when helpful.

Ongoing improvement

Accessibility is an ongoing practice. S&L welcomes practical feedback and will use it to improve the experience.
