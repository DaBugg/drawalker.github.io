ADDISON TRACE WEBSITE

This version is a gentle update of the original Addison Trace website. It keeps the familiar colors, simple navigation, community information, photos, and direct phone contact while improving readability and mobile support.

The active website uses AI enhanced WebP photographs stored in images/enhanced. Untouched source photographs are retained in images/originals.

Open index.html in a modern web browser to view the site.

Main files:
index.html     Website content
styles.css    Layout and appearance
script.js     Small mobile menu and current year update

Property details, listings, prices, community fees, rules, and school information should be independently verified before publication and before a real estate decision.
