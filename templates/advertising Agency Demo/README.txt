LGPR STATIC WEBSITE

This is a complete static website with no build process and no server runtime.

FILES
- index.html contains all HTML, CSS, and JavaScript.
- images, features, and logos contain the website's image assets.
- favicon.svg and og.png contain the browser and sharing artwork.

VERCEL
1. Put this entire folder in a Git repository.
2. Import the repository at vercel.com/new.
3. Choose "Other" if Vercel asks for a framework preset.
4. Leave Build Command and Output Directory empty.
5. Deploy.

You can also open index.html directly in a browser for a local preview.
