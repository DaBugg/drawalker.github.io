# Harborline redesign notes

- **Archetype:** Editorial project portfolio and investor narrative
- **Reference:** Hines editorial restraint, project scale, and investment context
- **Audience:** Private investors, family offices, landowners, lenders, development partners
- **Primary CTA:** Request the investment overview
- **Visual direction:** Limestone, charcoal, muted bronze, deep green, thin rules, full-bleed media
- **Motion:** Restrained media treatment and map state changes; no repeated entrances
- **Libraries:** Native JS; MapLibre, Chart.js, Swiper, and PhotoSwipe deferred until verified data/media exist
- **Interaction:** Accessible project-map fallback selector
- **Media required:** Drone video, architectural exteriors, site plan, neighborhood, progress, investor report
- **Changed structure:** Thesis, project portfolio, map, process, research, and confidential overview
- **SEO/accessibility:** Noindex, unique metadata, clear fictional metric labels, labeled form and keyboard controls
