# Template gallery redesign notes

- **Archetype:** Editorial marketplace and portfolio index
- **Audience:** Prospective clients comparing strategic website directions
- **Primary CTA:** Open a concept
- **Secondary CTA:** Use this direction
- **Visual direction:** Neutral gallery, asymmetric preview scale, project-led color, strong metadata
- **Motion:** Native filter reflow and featured-state changes
- **Libraries:** Native CSS and JS; Swiper and masonry packages intentionally avoided
- **Interaction:** Category filters, grid/list view, and featured concept controls
- **Preview system:** Each concept uses a distinct CSS-authored placeholder matching its hero and palette
- **Accessibility:** Keyboard buttons, visible focus, semantic links, and reduced motion
