# SitePilot redesign notes

- **Archetype:** Interactive product demonstration
- **Reference:** Samsara outcome framing and MaintainX frontline workflow clarity
- **Audience:** Operations leaders managing crews, work orders, materials, assets, and exceptions
- **Primary CTA:** Book a product demo
- **Visual direction:** Black, crisp white, lime product accent, dense interface panels
- **Motion:** UI state transitions only; no page parallax
- **Libraries:** Phosphor Icons; Chart.js and Swiper avoided because native UI states carry the story
- **Interaction:** Role-based dashboard switcher plus four-stage workflow demo
- **Media required:** Dashboard, mobile app, work detail, inventory, crew schedule, evidence, alerts, reporting
- **Changed structure:** Product appears immediately, followed by roles, workflow, modules, mobile, security, demo
- **SEO/accessibility:** Noindex, FAQ schema, keyboard controls, visible focus, labeled form, reduced motion
