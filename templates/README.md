- `forgeworks-industrial` — technical manufacturing procurement and RFQ

- `template-gallery` — asymmetric concept library with filters and list view

## Review locally

Serve this directory with any static web server, then open `template-gallery/index.html`. Direct file opening also works.

## Fictional-content and SEO default

The industry concepts remain `noindex, nofollow`. All companies, people, projects, metrics, ratings, availability, coverage, and product capabilities are illustrative until replaced and verified. See each folder's `REDESIGN-NOTES.md` and `SEO-README.md`, plus `REDESIGN-SUMMARY.md` at the collection root.

## Phase 5 SEO

`SEO-IMPROVEMENT-PLAN.md` defines the verified-content, search-intent, page architecture, structured-data, technical launch, indexing, and measurement process for adapting a concept to a real business. The fictional sites remain excluded from search until its launch gate is complete.

`PHASE-5A-BUSINESS-FACT-SHEET.md` is the intake, evidence register, concept-selection rubric, and approval gate for the first real adaptation.
