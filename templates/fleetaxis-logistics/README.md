# FleetAxis Logistics

Static HTML landing page concept.

## Open locally

Open `index.html` in a browser, or run a local server:

```bash
python3 -m http.server 8000
```

## Files

- `index.html`
- `styles.css`
- `script.js`
- `privacy.html`
- `terms.html`
- `404.html`
- `SEO-README.md`
- `assets/hero-visual.svg`
- `assets/og-image.svg`
- `assets/favicon.svg`
